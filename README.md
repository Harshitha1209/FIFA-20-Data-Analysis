
# FIFA 20 Data Analysis

## Project Overview

This project explores FIFA 20 player data using Python to identify patterns and insights related to player attributes, overall ratings, age, nationality, and player groupings. It combines Exploratory Data Analysis (EDA), data visualization, and unsupervised machine learning techniques to better understand the dataset.

## Objectives

- Analyze player attributes and overall ratings.
- Identify countries with the highest number of players.
- Explore correlations between different player skills.
- Investigate the relationship between player age and overall rating.
- Apply clustering techniques to explore similarities between players.
- Visualize player clusters using Principal Component Analysis (PCA).

## Technologies Used

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook

## Key Analysis

- **Exploratory Data Analysis:** Examine data distributions, missing values, and player characteristics.
- **Country-wise Analysis:** Visualize the top 10 countries by player count.
- **Correlation Analysis:** Explore relationships among player skills such as shooting, passing, dribbling, and defending.
- **Age and Rating Analysis:** Investigate how average overall ratings vary with player age.
- **Player Clustering:** Explore player groupings using K-Means, Agglomerative Clustering, and DBSCAN.
- **PCA Visualization:** Represent player groupings in a two-dimensional space.

## Project Outcome

The project provides hands-on experience in data preprocessing, exploratory data analysis, visualization, dimensionality reduction, and unsupervised machine learning. It helps develop an understanding of player characteristics and patterns within the FIFA 20 dataset.

## Tools and Environment

The analysis was developed using Python in Jupyter Notebook.
